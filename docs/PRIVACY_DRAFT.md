# Privacy Policy (draft) — LovePDuo

Last updated: 2026-10-05  
Contact: repository owner / app.lovepduo

## What we collect

- Account display name and pair code linkage
- Game session scores / presence needed for realtime play
- Uploaded audio files and metadata stored for the pair library
- Optional provider metadata (Spotify/VK) when user adds tracks

## What we do not do (MVP)

- No sale of personal data
- No advertising ID harvesting in MVP
- No reading contacts / SMS
- No promise of offline full Spotify/VK catalogs

## Pair content

Content inside a pair (notes, tracks, game memories) is private to that pair.  
Unlink pair removes local session association; server retention TBD when cloud backend ships.

## Uploads

You are responsible for rights to any audio you upload.

## Contact / deletion

Request account/pair data deletion via the developer contact on the store listing.

This draft will be finalized before Play production release.
